## #279 is the blocker, and it is not a regression

The `-q4` pack declares architecture `qwen4-exp`. `ds4.c:6803` dispatches on
the exact string `qwen4exp`. A pack that declares the hyphenated spelling
falls through to DeepSeek and dies on `deepseek4.block_count`.

`git log -S'"qwen4-exp"' -- ds4.c` returns nothing, so the engine never
accepted that spelling. This is a mismatch that was always there, surfaced by
the move — not something the move broke. The q4k-imatrix pack loads fine.

Four ways out, none chosen: rewrite the pack's GGUF metadata (note GGUF
strings are length-prefixed, so `qwen4-exp` -> `qwen4exp` shifts every
subsequent offset in a 74 GB file), repoint the six drivers at a pack that
loads, teach `ds4.c` to accept both spellings, or retire the affected
backends. **#228 cannot land until this is decided.**

## What shipped last

**#276 — do maximum fans make the GPU faster?** Answered and closed.
Maximum fans hold the die **8.48 C** cooler and buy **0.6% decode**, which is
reconciled by **+0.78% SoC power**: the cooling is real and it buys almost
nothing, because this chip was not thermally limited to begin with. On auto,
peak die hit 99.61 / 99.39 / 99.41 C across the three segments. A +1.8%
prefill reading was discounted — the pairs trend 4.4% -> 1.8% -> 0.9%, which
is a first-phase artifact, not an effect.

Secondary result, and the more useful one operationally: cooling on maximum
fans saves roughly **45 minutes per six-phase A/B** and reaches a
die-to-ambient delta of 5.2 C against 10-11 C on auto.

All raw data is in `benchmarks/ds4/fan-ab-276/` — 144 rows x 49 columns with
no blanks, per-second sensors, 18 raw CSVs, the manifest and the run log. It
was kept complete deliberately, for a possible write-up.

The method that came out of it is in `docs/m5max-runbook.md` under "Thermal
tests: what a fan or cooling comparison must do". The finding worth carrying
to any other project: **a threshold on a difference is a rate limit nobody
wrote down.** The original settle gate accepted 0.3 C between consecutive 30 s
medians, which restates as **36 C/hour**. It was replaced with a least-squares
slope over a trailing window, bounded at 0.3 C/min — calibrated against a
settled die's own noise (p90 0.277 C/min, n=820), not guessed.
