## The one that costs us something

[#149](https://github.com/evanwtf/local-llm/issues/149). ivanfioravanti measured, on an M5 Max with GLM-5.3-Flash-Q2, that ds4's automatic Metal 4 TensorOps route drifts from the reference kernels by whole logit units. We reproduced it here:

```
worst_rms=1.38592  worst_max_abs=7.26952     (his: 1.39, 7.27)
long_code_audit    greedy token mismatch step=0  ref=785 cand=1782
short_reasoning_plain  rms=0                 bit-identical
```

Short prompts are exact; **long prompts flip the first sampled token**, and one failing case is a code audit -- the shape of our whole agent suite. All four of our ds4 arms run the route, there is no opt-out env var in those builds, and preflight has been logging `Metal tensor API is on` at the head of every run without anyone reading it as a warning.

This does not invalidate the #138 comparison -- both arms ran the same route -- but it does mean no ds4 Metal quality number here should be called exact until the route is recorded per row and gated in preflight.
