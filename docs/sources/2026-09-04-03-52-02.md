## Method correction, for the skill

**Surface 1's command hides read notifications.** The skill's `gh api notifications` returns
unread only, so a mention that has been opened -- on any device -- is invisible to the sweep.
This sweep reported "no mentions" on its first pass and was wrong: eight were there, three
from that day. Use `gh api "notifications?all=true&per_page=100" --paginate` instead, and
filter `ci_activity` out rather than relying on the wall of them to be the whole inbox.
